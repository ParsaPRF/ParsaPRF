## 👋 About Me

- 🎓 **Computer Science student** in Tehran — I learn by shipping, not by watching.
- 🧩 **Full-stack engineer at heart:** Django REST APIs with real tests, migrations, CI and ADRs, paired with React + TypeScript front-ends.
- 🤖 **Automation & AI:** subtitle/translation pipelines (Groq Whisper, Gemini, OpenRouter), media downloaders built on `yt-dlp`, and Telegram bots wired with **aiogram**.
- 📚 **Documentation nerd:** I keep an exam-ready Persian **Obsidian** vault on software engineering, and I write ADRs and handover docs for my own projects.
- 🎮 **Off the web:** Godot 4 game dev, plus motion graphics and editing in After Effects / Premiere / Photoshop.

> [!NOTE]
> 🔭 **Currently building** a private, bilingual Telegram content-intelligence bot — source discovery → AI editorial pipeline → scheduled publishing — built on **aiogram**, with SQLite-backed atomic-claim queues and a scheduler loop. Also polishing **Engineering Issue Tracker**, my flagship Django + React project.
